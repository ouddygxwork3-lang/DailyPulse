# DayPulse — ตารางงานรายวัน & แจ้งเตือนส่งงานข้ามอุปกรณ์ (PC • iOS • Android)

เว็บแอปพลิเคชันแบบ **All-in-One Progressive Web App (PWA)** สำหรับจัดการตารางงานที่มีจำนวนมากในแต่ละวัน แยกประเภท **"งานที่ต้องทำระหว่างวัน"**, **"งานที่ต้องส่ง (Submissions / Deadlines)"** และ **"นัดหมาย"** อย่างชัดเจน พร้อมระบบแจ้งเตือนตรงเวลาผ่าน **PWA Web Push**, **เสียงเตือนในแอป** และ **Telegram Bot**

## ฟีเจอร์เด่น
- **แยกชัดเจนระหว่าง งานทำ vs งานส่ง**: ระบุผู้รับ ช่องทางส่ง และแนบลิงก์ไฟล์ส่งงานไว้ในการ์ดเดียว พร้อมหน้า **ศูนย์เช็กของต้องส่ง (Submissions Radar)**
- **พิมพ์รวดเดียวหลายงาน (Brain Dump)**: พิมพ์หลายบรรทัด เช่น `14:00 ส่งรายงานยอดขายให้พี่เอก @LINE !ด่วน` ระบบแยกเวลา ประเภทงาน ผู้รับ และระดับความสำคัญให้อัตโนมัติ
- **เทมเพลตงานประจำวัน (Routine Templates)**: กดปุ่มเดียวสร้างชุดงานประจำลงตารางวันนี้ทันที และบันทึกตารางวันนี้เก็บเป็นเทมเพลตใหม่ได้
- **ยกยอดงานค้าง (One-Click Rollover)**: รวมงานที่ยังไม่เสร็จจากวันก่อนมาไว้ในวันนี้ด้วยปุ่มเดียว
- **โหมดโฟกัส (Focus Timer / Pomodoro)**: จับเวลาโฟกัสผูกกับงานที่กำลังทำ (15 / 25 / 45 นาที)
- **ซิงค์และแจ้งเตือนข้าม PC, iOS และ Android**:
  - ซิงค์หน้าจอสดแบบ Real-time ผ่าน Server-Sent Events (SSE) + โหมดแคชออฟไลน์
  - แจ้งเตือนล่วงหน้าหลายจังหวะ (`ก่อน 5/15/30/60 นาที` + `ตรงเวลา`), ปุ่มเลื่อนเวลาเตือน (`Snooze`) และ **สรุปงานประจำวันตอนเช้า (Daily Briefing)**

## วิธีรันใช้งานบนเครื่อง (Local Development & Production)

```bash
# 1. ติดตั้งแพ็กเกจ
npm install

# 2. รันโหมดพัฒนา (เปิดทั้ง Backend Server + Vite Frontend)
npm run dev
# เปิดเบราว์เซอร์ที่ http://localhost:5173

# 3. สร้างไฟล์ Production และรันรวมในพอร์ตเดียว (http://localhost:3000)
npm run build
npm start
```

## วิธีนำขึ้นออนไลน์ฟรีเพื่อซิงค์และยิง Push เข้ามือถือ iOS / Android ตลอด 24 ชม.

> **หมายเหตุสำคัญสำหรับมือถือ iOS / Android:** ระบบ Web Push ของเบราว์เซอร์มือถือบังคับให้เว็บไซต์ต้องเปิดผ่าน **HTTPS** เท่านั้น
> - บน **iPhone / iPad (iOS 16.4+)**: เปิดลิงก์ HTTPS ใน **Safari** -> กดปุ่ม **แชร์ (Share)** -> เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)** -> เปิดแอปจากไอคอนบนหน้าจอโฮม -> ไปที่เมนู **ตั้งค่าแจ้งเตือน** -> กด **"เปิดรับแจ้งเตือนบนเครื่องนี้"**

### ทางเลือกที่ 1: Deploy ขึ้น Railway หรือ Render (แนะนำ — ออนไลน์ 24 ชม.)
ในโปรเจกต์เตรียมไฟล์ `Dockerfile`, `railway.json` และ `render.yaml` ไว้ให้พร้อมแล้ว:
1. อัปโหลดโค้ดชุดนี้ขึ้น GitHub Repository (แบบ Private ได้)
2. เข้าเว็บ [Railway.app](https://railway.app) หรือ [Render.com](https://render.com) แล้วเลือก **New Web Service from GitHub Repo**
3. ผูก Persistent Volume ที่โฟลเดอร์ `/app/data` เพื่อเก็บไฟล์ฐานข้อมูล SQLite ถาวร แล้วกด Deploy เพื่อรับลิงก์ `https://...` ไปเปิดทั้งบน PC, iOS และ Android ได้ทันที!
